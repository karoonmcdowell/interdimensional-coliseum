# Approved character sprite assets

This bundle includes the **actual transparent PNG frame strips extracted from the approved character design sheet**, unchanged. Each is 416 × 76 px (four 104 × 76 frames). `preview.html` provides a standalone animated preview.

GitHub `develop` has been updated to use these PNG files instead of code-drawn silhouettes, but the binary image files have **not yet been uploaded to the repository**. To complete the GitHub deployment, place the `assets/characters/` directory at the repository root and review on a development preview before merging to `main`.

The concept sheet provides no separate Bastion teleport animation; the loader temporarily aliases the dash strip for teleport. This should be replaced with an approved pose sequence later.
